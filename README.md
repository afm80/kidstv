# تلفزيون الأطفال — النظام التلقائي للفيديوهات

## الملفات
1. `index.html` — التطبيق (تطبيق ويب PWA)
2. `sw.js` و`manifest.json` — التثبيت والعمل دون اتصال
3. `firebase-config.js` — إعدادات Firebase للقراءة في المتصفح
4. `sync.py` — سكربت المزامنة مع يوتيوب
5. `.github/workflows/auto-sync.yml` — تشغيل المزامنة كل ساعة
6. `channels.txt` — قائمة القنوات والفيديوهات (رابط في كل سطر، والأسطر التي تبدأ بـ `#` تُتجاهل)

## الإعداد
1. ارفع المشروع كاملاً (مع مجلد `.github`) إلى مستودع GitHub.
2. من Settings ← Secrets and variables ← Actions أضف سرّين:
   - `YOUTUBE_API_KEY`: مفتاح YouTube Data API v3
   - `FIREBASE_DB_URL`: رابط قاعدة Realtime Database، مثل `https://xxxx-default-rtdb.firebaseio.com`
3. شغّل Workflow يدوياً من تبويب Actions للتجربة، ثم يعمل تلقائياً كل ساعة.

## ما يفعله السكربت
- يجلب آخر فيديوهات القنوات الموجودة في `channels.txt` والفيديوهات المباشرة الفردية.
- يضيف البث الجاري لقسم "قنوات البث" والباقي لقسم "فيديوهات".
- يتجاهل الشورتس (أقل من دقيقة) والبث المجدول الذي لم يبدأ بعد.
- يمنع التكرار، وينقل الفيديو من "قنوات البث" إلى "فيديوهات" عند انتهاء البث.
- لا يحذف الفيديوهات القديمة من القاعدة.

## ملاحظات
- GitHub يوقف الجدولة تلقائياً بعد 60 يوماً دون أي نشاط في المستودع العام؛ شغّل Workflow يدوياً لإعادة تفعيلها.
- قواعد `database.rules.json` تسمح بالكتابة العامة على `videos` و`categories` لأن السكربت يكتب دون مصادقة. للحماية الكاملة استخدم حساب خدمة (Service Account) في السكربت وأغلق الكتابة العامة.
